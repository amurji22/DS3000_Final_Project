# Predicting EV Energy Consumption

As electric vehicle (EV) adoption grows, both public charging providers and drivers face increasing uncertainty around power demand. Providers need better insight into how much energy sessions will draw, while drivers often arrive at chargers without clear estimates of how much energy their car will consume.

This project builds machine learning models to:

- Predict **energy consumption per charging session**
- Compare the performance of different regression models using metrics such as RMSE, MAE, and R²
- Explore how session and vehicle-related features relate to EV charging energy use

## What’s in this repo

- Data preprocessing and feature engineering for EV charging sessions  
- Model training and evaluation code for predicting energy consumption  
- Experiments comparing several regression models

## Goals

- Provide more accurate expectations of energy use for individual charging sessions  
- Help charging providers better understand and plan for power demand
